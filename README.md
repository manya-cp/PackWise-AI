# 🧳 PackWise AI

### Pack less. Travel smarter. Explore better. 🌎

PackWise AI is an intelligent travel packing assistant that helps travelers prepare personalized packing plans based on their destination, trip duration, trip type, and luggage.

## ✨ Features

- 🤖 AI-powered travel packing assistant
- 📸 Travel item image analysis
- 🧳 Personalized packing recommendations
- ✅ Smart interactive packing checklist
- 📊 Packing progress tracking
- 📧 Personalized travel plan delivered by email
- 🌎 Destination-aware recommendations
- 💬 Conversational AI assistance

## 🛠️ Tech Stack

- Python
- Streamlit
- Google Gemini API
- Resend Email API
